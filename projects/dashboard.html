Descripción del Proyecto Project Description

Este dashboard interactivo presenta un análisis comparativo de las métricas de ventas entre los años 2023 y 2024. Desarrollado con HTML, CSS y Chart.js, permite visualizar tendencias de ingresos, distribución regional y rendimiento por producto de forma clara y atractiva. This interactive dashboard presents a comparative analysis of sales metrics between 2023 and 2024. Developed with HTML, CSS, and Chart.js, it allows clear and attractive visualization of revenue trends, regional distribution, and product performance.
